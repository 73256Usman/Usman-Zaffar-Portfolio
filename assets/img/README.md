# Photos

Put your headshot here and name it `usman.jpg` (JPG or WebP renamed to .jpg is fine, around 800 pixels wide is plenty).
It appears next to the About text automatically. If the file is missing, the About section simply shows the text on its own.

Tips: a plain or softly blurred background, good light on your face, shoulders up, dressed the way you would for an interview.
To use a different file name or add alt text changes, edit `photo` and `photoAlt` in `assets/js/data.js` under `profile`.
